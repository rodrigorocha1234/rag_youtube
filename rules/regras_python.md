# Regras Python
- Python mínimo: 3.12.
- Nomes próprios em português.
- Uma classe principal por arquivo.
- Métodos devem representar ações com nomes verbo_substantivo.
- Evitar God Classes, métodos longos, duplicação e abstrações cerimoniais.
- Preferir composição; herança apenas quando houver relação semântica real.
- Usar `typing.override` em sobrescritas.
